Wang Tiling LaboratoryA browser-based logic simulation and procedural generation tool based on Wang Tiles and Wave Function Collapse (WFC).
FeaturesAlgorithms: Linear Scan and Wave Function Collapse (Entropy-based).
Visualization: Standard 2D, Pipes/Circuit view, and 2.5D Isometric projection.
Logic: Backtracking solver with lookahead constraints.
Game Modes: Puzzle Mode (Manual), Campaign (Pipe connection), and Infinite "Living" Mode.Persistence: Save/Load state via JSON and export high-res snapshots.
How to Run: Simply open index.html in any modern web browser. No build step or server required.TechnologiesVanilla JavaScript (ES6 Modules)HTML5 CanvasCSS3 Variables
